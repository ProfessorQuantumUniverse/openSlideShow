# 1.4.0 — Video Support

Feature release: videos are now part of the show.

### 🎥 Video support
Videos in the media folder play along with the images, and always **play to the end** before the show moves on.
- **Formats:** MP4 / M4V / MOV (H.264, H.265¹, AV1), WebM / MKV (VP8, VP9, AV1), OGV
- **Native playback** through Chromium's built-in media pipeline with **hardware decoding**. No external player, no transcoding.
- **All transitions work with videos**, and the sound of the outgoing video fades out smoothly.
- **Blur-fill for videos too**, so portrait clips get no black bars. The background is drawn live from the playing video (128 px GPU downsample, no second decoder).
- The next video is **preloaded up to its first frame**, so transitions never fade into black. Each video's decoder is freed right after its slide.
- **Pause** also pauses the video. **Video sound** on/off and **volume** are new live controls in the control panel. The preview stays muted and shows the **playback time + a progress bar**.
- **Robust for live use:** broken or unsupported files are skipped automatically, and so is a video that makes no progress for 12 s. The show never gets stuck.
- **Date sort** now also reads the recording time stored in MP4/MOV files.

<sub>¹ H.265/HEVC only where the GPU / Windows supports hardware decoding.</sub>

### 🐞 Fixes
- Rapid next/prev could let a late transition-end event hide the wrong layer. Transition cleanup now runs synchronously.
- Changing settings (overlay text, look …) no longer restarts the current slide's timer. Only a changed display duration does.
